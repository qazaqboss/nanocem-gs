# NanoCem GS

Сайт продукта NanoCem GS — водоизоляция подошвенной воды и консолидация песчаника в газовых скважинах за одну обработку. Главный элемент — интерактивный изометрический разрез скважины с шестью стадиями процесса (стрелки ← → или кнопки под схемой).

## Структура

- `index.html` — разметка страницы
- `assets/style.css` — стили (светлая и тёмная темы)
- `assets/main.js` — анимация разреза и переключение стадий

## Локальный запуск

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
